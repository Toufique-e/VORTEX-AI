# VORTEX Rover v15 — Clean Final Release Notes

## Release focus

This clean package contains only the files required to build, configure, operate, validate and locally preview the VORTEX rover. Development scratch files, duplicate previews, original reference copies and the full internal test harness are intentionally omitted.

## Included system capabilities

- ESP32-CAM direct MJPEG streaming with optional UART camera housekeeping.
- ESP32 DevKit motor control, AI safety state machine, odometry and dashboard hosting.
- Laptop-side YOLOv8n + BoT-SORT human detection/tracking.
- Predictive human occupancy and approach detection.
- Side-clear confirmation, blocked-by-humans hard stop and slow recovery.
- AI lease, sequence validation, watchdogs and motor command expiry.
- Manual takeover from AI mode.
- AI-health and latency diagnostics.
- Landscape laptop dashboard plus separate camera settings page.
- Local dashboard/settings preview.

## Branding

The project name is **VORTEX** throughout this clean release.
